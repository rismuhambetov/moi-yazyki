# Мои языки — китайский и английский

Бесплатный тренажёр: 2 209 слов HSK 1–3, около 3 000 важных английских слов, книги с переводом,
диалоги, режим «в наушниках», тренажёр тонов и ИИ-учитель (Claude).

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html` | весь сайт (один файл) |
| `config.js` | одна настройка — адрес сервера ИИ |
| `LICENSES.txt` | лицензии использованных открытых словарей (обязательно оставить) |
| `worker/worker.js` | сервер-посредник для ИИ (Cloudflare Worker) |
| `worker/wrangler.toml` | настройки посредника для запуска из командной строки (необязательно) |

Без ИИ сайт работает сразу: карточки, словарь, книги, диалоги, тоны. ИИ подключается шагами 2–4.

---

## Шаг 1. Выложить сайт на GitHub Pages (бесплатно)

1. Зарегистрируйтесь на <https://github.com>.
2. Нажмите **New repository** → имя, например `moi-yazyki` → **Public** → **Create repository**.
3. На странице репозитория: **Add file → Upload files** → перетащите `index.html`, `config.js`, `LICENSES.txt`, `README.md` → **Commit changes**.
4. **Settings → Pages** → *Source*: **Deploy from a branch** → ветка `main`, папка `/ (root)` → **Save**.
5. Через 1–3 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/moi-yazyki/`.

## Шаг 2. Ключ Anthropic API (ИИ платный — платит владелец ключа)

1. Зарегистрируйтесь в консоли Claude: <https://platform.claude.com>.
2. В разделе оплаты (Billing) пополните баланс.
3. **Обязательно** задайте месячный лимит расходов (Limits / Spend limit) — это главная защита от неожиданных счетов.
4. **API Keys → Create Key** — скопируйте ключ.

⚠️ Ключ **никогда** не вставляйте в `config.js`, `index.html` или на GitHub — его украдут. Он хранится только в Cloudflare (шаг 3).

## Шаг 3. Сервер-посредник на Cloudflare (бесплатно)

1. Зарегистрируйтесь на <https://dash.cloudflare.com>.
2. **Workers & Pages → Create → Worker** (шаблон «Hello World») → имя `moi-yazyki-ai` → **Deploy**.
3. **Edit code** → удалите всё и вставьте содержимое `worker/worker.js` → **Deploy**.
4. Worker → **Settings → Variables and Secrets**:
   - **Secret** `ANTHROPIC_API_KEY` = ваш ключ из шага 2;
   - **Text** `ALLOWED_ORIGINS` = `https://ВАШ-ЛОГИН.github.io` (без `/moi-yazyki` и без `/` в конце).
5. Скопируйте адрес Worker — вида `https://moi-yazyki-ai.ВАШ-ЛОГИН.workers.dev`.

Встроенная защита: посредник отвечает только вашему сайту, использует недорогую модель `claude-haiku-5-5`,
ограничивает длину запросов и ответов и пускает не больше ~8 запросов в минуту с одного устройства.
Для надёжного лимита на уровне всей сети Cloudflare разверните через командную строку:
`cd worker && npx wrangler deploy && npx wrangler secret put ANTHROPIC_API_KEY`
(в `wrangler.toml` замените `ВАШ-ЛОГИН`).

## Шаг 4. Подключить ИИ к сайту

На GitHub откройте `config.js` → карандаш (**Edit**) → впишите адрес Worker:

```js
window.APP_CONFIG = { AI_URL: "https://moi-yazyki-ai.ВАШ-ЛОГИН.workers.dev" };
```

→ **Commit changes**. Через минуту на сайте появятся вкладка «🤖 ИИ», «Объясни слово», генерация книг и диалогов.

## Перенос своего прогресса с claude.ai

Старая версия: ⚙️ → **Перенос прогресса → Скопировать код**.
Новый сайт: ⚙️ → вставьте код в поле → **Загрузить код**.

## Что стоит денег

- Хостинг GitHub Pages и Cloudflare Workers — бесплатно (в пределах их бесплатных лимитов).
- Голос — бесплатный голос браузера. Лучше всего звучат «Natural»-голоса в Microsoft Edge и голоса Google в Chrome.
- ИИ — оплата Anthropic за каждый запрос всех пользователей; контролируйте лимитом расходов в консоли.
